4.
Code Coverage 80% หมายถึงอะไร?

ก.
โปรแกรมใช้ทรัพยากรเครื่องไป 80% ขณะรัน Test

ข.
ฟังก์ชันทำงานถูกต้อง 80% ของกรณีทั้งหมด


ค.
80% ของจำนวนบรรทัดในซอร์สโค้ดถูกรันโดยชุดทดสอบอย่างน้อยหนึ่งครั้ง

คำตอบถูกต้อง
Coverage วัดว่าชุดทดสอบของเราครอบคลุมการรันบรรทัดโค้ดในโปรแกรมหลักมากน้อยเพียงใด

ง.
โปรแกรมของเราไม่มี Bug แน่นอน 80%

5.
ทำไมเราถึงควรเขียน Test สำหรับ Edge Cases (กรณีขอบเขต)?

ก.
เพื่อให้โค้ดดูยาวและซับซ้อนขึ้น

ข.
เป็นกฎบังคับของภาษา Python

ค.
เพื่อให้รัน Test ได้เร็วขึ้น

ง.
เพื่อตรวจสอบว่าโปรแกรมรับมือกับข้อมูลที่ผิดปกติหรือค่าที่คาดไม่ถึงได้หรือไม่

คำตอบถูกต้อง
Edge Cases เช่น ข้อมูลว่างเปล่า หรือเลขติดลบ มักเป็นจุดที่ทำให้โปรแกรมแครชถ้าไม่ได้เตรียมการไว้
