#-------------------------------------Clean Repo (Action)------------------------------------------ ก่อนจะปิดโปรเจกต์ เราต้องกำจัด "ขยะ" ที่ไม่ได้ใช้งานออกไปเพื่อให้ Repository ของเราดูเป็นมืออาชีพ:

ลบไฟล์ขยะ: ลบพวก test.py, debug_temp.txt หรือไฟล์ที่คุณสร้างขึ้นมาเพื่อลองเล่นสั้นๆ

จัดการ Folder Structure: จัดกลุ่มไฟล์ให้เป็นระเบียบ

/src หรือ /app: เก็บ Code หลัก (เช่น library_system.py)

/tests: เก็บไฟล์ที่ขึ้นต้นด้วย test_*.py ทั้งหมด

สร้าง .gitignore: (สำคัญมาก) ระบุสิ่งที่ Git ไม่ต้องนำขึ้นไป เช่น:

__pycache__/ (ไฟล์คอมไพล์ของ Python)

.pytest_cache/

.env (ไฟล์เก็บความลับ)

Formatting: ใช้เครื่องมืออย่าง Black หรือจัด Format ใน VS Code ให้โค้ดสวยงามสม่ำเสมอทั้งโปรเจกต์
