Debugging: กระบวนการหาต้นเหตุของ Error (Bug)
Print Debugging: การใส่ print() เพื่อดูค่าตัวแปร (วิธีพื้นฐาน)
Debugger Tool: การใช้ Breakpoint ใน VS Code เพื่อหยุดเวลาดูสถานะโค้ดทีละบรรทัด
Logging: การจดบันทึกเหตุการณ์ที่เกิดขึ้นในโปรแกรมลงในไฟล์ แทนการ print หน้าจอ

ระดับของ Log: DEBUG -> INFO -> WARNING -> ERROR -> CRITICAL

📝 สรุปสิ่งที่ได้เรียนรู้ (README)
Logging > Print: ในระบบจริงเราไม่ใช้ print เพราะมันลบทิ้งยาก แต่ logging สามารถปิด-เปิด หรือบันทึกลงไฟล์เพื่อมาดูย้อนหลังได้เมื่อเซิร์ฟเวอร์มีปัญหา

Try-Except is a must: การคาดการณ์สิ่งที่อาจจะพัง (เช่น User พิมพ์ตัวอักษรแทนตัวเลข) จะทำให้โปรแกรมไม่ Crash

Debugger: การใช้ Breakpoint ใน IDE (จุดแดงหน้าเลขบรรทัด) จะช่วยให้เราเห็น "ลำดับความคิด" ของคอมพิวเตอร์ได้ชัดเจนที่สุด
