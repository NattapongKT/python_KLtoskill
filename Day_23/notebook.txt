Concepts
ในการทำงานจริง เราจะไม่แก้โค้ดที่หน้างาน (Main branch) ตรงๆ แต่จะใช้ Feature Branch Strategy เพื่อแยกงานแต่ละส่วนออกจากกัน
Main Branch: โค้ดที่ใช้งานจริง (ต้องสะอาดและรันได้เสมอ)
Feature Branch: กิ่งที่แตกออกมาเพื่อทำฟีเจอร์ใหม่ เมื่อเสร็จแล้วค่อยนำไปรวม (Merge) กลับเข้า Main
git merge: การรวมโค้ดจากกิ่งหนึ่งเข้าสู่อีกกิ่งหนึ่ง
